Ask about a pilot, an evaluation or a number

Respite runs on the recording company's own machine, so recordings never leave it. This page says how to reach us and what to include.

Pilots and evaluations

If you record robot training data, or buy it, and want this benchmark's checks run on a batch of yours, get in touch through respitelabs.net. It helps to say what you record (robot, cameras, recorder format) and roughly how many hours a week. We report, per station, what the checks find and where they cannot see.

Questions about this study

For a question or a correction about a number, the method or the data, open an issue on this site's repository. Every number on the site is listed with the stored file it came from in data/claims.json; quoting the number's path there makes it quick to check.

The benchmark code is in Respite's repository, which is private today. Access for an evaluation is available on request through the same channels.

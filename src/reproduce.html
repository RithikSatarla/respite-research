Reproduce

What you can rerun, and what you can check

The benchmark code lives in Respite's repository, which is private today. Everything a reader needs to check the published numbers is here: the result tables, the per-trial outcomes, the frozen design and hashes, and the public dataset. Access to the code for an evaluation is available on request.

Published files

  • data/results.json: every number on this site.
  • data/tables/trials.csv: every scored test trial for every detector (one row per trial; XDOF episode identifiers are public).
  • by_fault.csv, by_station.csv, ablations.csv, curves.csv, calibration.csv.
  • data/tables/hflow_per_episode.csv: the HFlow comparison, one row per file, with both scorings.
  • data/demo.json: the stored records behind the interactive demo.
  • data/MANIFEST.json: SHA-256 of every published data file and figure, and the source commit ({{ meta.source_commit }}).

Development-set results (the team dataset) are published only as aggregates: the dataset's licence is not recorded and its owner is not named.

Run it (with repository access)

# Python 3.11 or 3.12 (the study used Python 3.11.1 with scikit-learn 1.9.1)
pip install -e ".[readers]" scikit-learn pytest mcap mcap-protobuf-support
python -m pytest tests                      # the whole suite, including the benchmark tests

# the frozen split (already in the repository; this regenerates the same file)
python experiments/splits/make_split.py

# development features: three draws of injected faults (data under data/yam)
python experiments/build_features.py --set dev --draw 101
python experiments/build_features.py --set dev --draw 202
python experiments/build_features.py --set dev --draw 303

# training on development data only; writes models and frozen thresholds
python experiments/train_model.py

# external test set: stripped and faulty MCAP copies, then features, then scoring
python experiments/xdof_variants.py --data data/xdof --out OUT/xdof_variants
python experiments/build_features.py --set test --variants OUT/xdof_variants
python experiments/benchmark.py --set test
python experiments/decide.py
python experiments/retrospective.py
python experiments/figures.py
python experiments/check_model_versions.py  # same model probabilities under each scikit-learn version

# HFlow comparison (HFlow 0.2.22 from PyPI, run under WSL2 or Linux). HFlow keeps a transformed copy of
# every file it tests in its data root (the third argument): put it on a drive with several GB free.
python experiments/hflow/make_hflow_set.py --data data/xdof --out OUT/hflow_set
python experiments/hflow/run_hflow.py OUT/hflow_set/files.json OUT/hflow_set/hflow_out.jsonl /tmp/hflow_runs
python experiments/hflow/compare.py --set OUT/hflow_set

Data

  • External test set: XDOF ABC-130k (Apache-2.0; access is gated on Hugging Face). The episode identifiers used are in trials.csv.
  • Development set: one robotics team's recordings, not redistributed here.
  • HFlow: github.com/Hebbian-Robotics/hflow, version 0.2.22 from PyPI.
